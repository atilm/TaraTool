# Controls

| ID        | Name                              | Security Goal                                                       | Active |
| --------- | --------------------------------- | ------------------------------------------------------------------- | ------ |
| C-TLS     | TLS encryption and authentication | Communication via the web API is secured.                           |        |
| C-SECBOOT | Secure Boot                       | Only software from the official developer can be run on the system. |        |
| C-SIGN    | Signed Applications               | Only software from the official developer can be run on the system. |        |
| C-TOKENS  | API Tokens                        | Only authenticated users can access the REST API.                   |        |
